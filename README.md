# Rainfall Analysis Dashboard

## Tools Used
- Snowflake
- SQL
- Power BI

## Project Overview
This project analyzes rainfall and agricultural data using Snowflake for data storage and SQL transformations and Power BI for visualization.

## Features
- Rainfall Group Classification
- Crop Analysis
- Yield Analysis
- Seasonal Trends
- Interactive Dashboard
